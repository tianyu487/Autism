# 图片审查标准 v0.2（草稿 · 待用户确认后才启用）

> 用途:每生成完 **一课** 的全部场景图后,由「图片审查 agent」逐页对照本标准审查。
> 审查 agent **只看图、只判定、不改图**;输出每页「通过 / 不通过 + 具体问题 + 建议动作」。

---

## 流程总览（闭环 · 不合格的图不呈现给用户）

```
内容agent 出图(一课)
      ↓
审查agent 逐页对照本标准判定 ──→ 全部通过 ──→ 交用户确认 ──→ 用户确认 ──→ 合成视频
      ↓ 有"不通过"页                                     ↑
主控自主派「优化agent」只重做这些页(换seed / 改visual_en)  │
      ↓                                                   │
审查agent 只复检被修的页 ──→ 仍不通过则再修 ───────────────┘（循环直到全通过）
```

- **关键规矩:被判「不通过」的图,绝不返回给用户。** 主控**自主**驱动「审查 → 优化 → 复审」闭环,
  直到该课**每一页都通过**,才把整套图交用户确认;整个修复过程不打扰用户、不展示不合格图。
- 三种 agent 分工:
  - **内容 agent**(每课一个):写该课**区别于其它课**的循证内容 + 出场景图;
  - **审查 agent**(全局一个):按本标准逐页判定、只回报,不改图、不合成;
  - **优化 agent**(按需派):针对某几页,复现管线出图路径换 seed / 改写 visual_en 重做,不碰别课别页。

---

## 0. 审查方式（怎么看）
- **逐张全分辨率查看**每一页场景图(不能只看缩略拼图 / contact sheet)。
- **眼睛、手** 是最易出错处,必须重点放大审视。
- 每页都要**对照该页的中文/英文文字**判断画面是否贴合(见标准 D)。
- 只审 `output/<课>/scenes/*.png` 里的成品页(插画 + 字幕已合成的那张)。

---

## 1. 硬性标准（命中任一 = 不通过,必须重做该页）

### A. 眼睛 👀（最高优先,每张必查）
- 睁眼的每个人物都要有:**清晰的黑色/深色瞳孔** + **可见的白色眼白(sclera)**。
- 双眼**对称**、朝向一致(不斜视、不对眼、不各看一边)。
- 眼神**明亮饱满有神**,有高光点(catchlight);不呆滞、不空洞、不发灰。
- **不允许**:瞳孔糊化 / 融化 / 破裂、无眼白、独眼、明显大小眼、眼球畸形。

### B. 脸 🙂
- 自然、端正的人脸;**不允许**扭曲、错位、拉伸、崩坏的脸。
- **前景与背景人物都算**(背景里被虚化的脸若明显扭曲,也算不通过)。

### C. 手与肢体 ✋
- 每只手 **五根手指**,数目正确;**不允许**多指 / 少指 / 手指粘连融合。
- **不允许穿透(穿模)**:手穿过另一只手、手/手指穿过物体(毛巾、玩具等)、肢体互相穿插。
- 不出现凭空多出的第三只手/手臂。

### D. 场景忠实 🎬
- 每页画面要**表现该页文字所述的具体场景 / 动作 / 对象**,而不是泛泛的「两个小孩站一起」。
- 参考示例:
  - 「看墙上的步骤图」→ 画面要有贴步骤图的墙 + 孩子抬头看图;
  - 「看旁边小朋友怎么做」→ 两个孩子,主角在看另一个正在做的孩子;
  - 「用毛巾擦手」→ 手里要有毛巾在擦手,毛巾颜色符合文字(如浅蓝色);
  - 主题道具(如小火车)应在相关页出现。

### E. 人数 / 单人页 👤
- 单人页(单人特写、鼓励页、单人题材的练习页)**只能有一个孩子**,不得出现复制的 / 多余的第二个孩子。
- 双人页人数正确(通常 2 人),不得凭空多出人物或残缺半身乱入。

### F. 页码角标 🔢
- 画面**任何位置都不得出现** 「1/4」「2/4」这类页码数字(及其它无关数字角标)。

### G. 乱码文字 🔤
- 插画本身**不得长出乱码文字 / 字母 / 伪单词**。
- (注:底部的中英文字幕是渲染层正常加的,不算问题;这里只针对画面里冒出来的乱字。)

### H. 画风统一 · 无图标/简笔页 🎨（每张必查）
- 每一页都必须是**统一的柔和绘本插画风、且画面里有人物**(主角小明,以及该页应出场的角色)。
- **严禁**任何"极简图标页 / emoji 图标 / 简笔画 / 纯色图标卡"这类**出图失败的回退页**——它们与其它页画风不一致,一律判**不通过**。
- 判断线索:画面是一个大图标 / 表情符号 / 极简线条 / 没有柔和光影与人物 → 就是图标回退页,不通过,**必须补出正常插画**(建议动作:`重出插画`,必要时换 seed)。

---

## 2. 软性标准（记录并提示;一般不重做,严重时才重做)
- **角色一致性**:同一课里主角/同伴的发型、脸型、服装跨页保持一致,不漂移。
- **背景模糊**:需要景深虚化的页,背景保持柔和虚化(如练习页的背景人物)。
- **构图 / 遮挡**:主体的脸不要被底部字幕框大面积压住;主体不过度偏出画面。
- **风格**:温柔、柔和、低刺激、绘本感,符合感官友好;肤色 / 配色自然。

---

## 3. 每页输出格式（审查 agent 必须这样回报)
逐页一行:

```
NN_页名 | 通过 / 不通过 | 命中的标准字母 + 具体问题 | 建议动作
```

- **建议动作**四选一:
  - `重出插画`——该页是图标/简笔回退页(H),缺正常插画,需重新生成插画(可配合换 seed);
  - `重掷seed`——画面构图对、但眼/手/脸有瑕疵,换 seed 重出该页;
  - `改visual_en`——画面不贴合文字(场景忠实 D 不达标),需改写该页画面描述;
  - `保留`——通过。
- 末尾给出:**不通过页清单** + 一句总体结论(如「19 页中 3 页不通过:04 / 13 / 17」)。

**示例:**
```
13_trial3_answer | 不通过 | A:右眼瞳孔糊化、双眼不对称     | 重掷seed
04_step3         | 不通过 | D:未体现"用毛巾擦手",手里无毛巾 | 改visual_en
08_trial1_reinforce | 通过 | —                          | 保留
```

---

## 4. 复检（自主闭环)
- 被判「不通过」的页,由主控**自主**派优化 agent 修复;审查 agent **只复检这些页**。
- 反复「修 → 复审」直到**全部通过**——过程中**不打扰用户、不展示不合格图**——再交用户确认。
- 设一个**上限**(如某页连修 4 轮仍不过):停下并把该页情况上报用户,由你定夺(避免无限循环)。

---

## 5. 边界（审查 agent 不做的事）
- 不改图、不改配置、不合成视频——只判定与回报。
- 不评断课程文字内容 / 循证性(那是内容层的事);只看**画面质量与贴合度**。
